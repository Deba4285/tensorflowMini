MNIST Digit Classification Using TensorFlow

📌 Project Overview

This mini project builds a handwritten digit classification model
using TensorFlow and the MNIST dataset.

The MNIST dataset contains handwritten images of digits from 0 to 9.
The model learns from the training images and predicts which digit is
present in an unseen test image.

This project is implemented using TensorFlow's low-level APIs to
demonstrate how a neural network works internally, including:

Data loading and preprocessing

Flattening image data

Normalization

Creating weights and biases

Forward propagation

Activation functions

Cross-entropy loss

Accuracy calculation

Gradient-based optimization

Model training

Test prediction

Visualizing predictions

🎯 Objective

The objective is to train a neural network that can classify MNIST
handwritten digit images into 10 classes (0--9).
